# NEARFEELD — Brand Guide

**Scent you carry.**
Minimal tech, quiet space. Deep black like open space, off-white line work, and one sage-green signal. The sage always means *the scent cell*.

---

## 1. Logo

The mark is a **source dot and three signal arcs**. The sage dot is the scent cell, and the arcs are the field it gives off: your *near field*.

| File | Use on |
|---|---|
| `brand/logo-mark-dark-bg.svg` | Black / dark backgrounds (default) |
| `brand/logo-mark-light-bg.svg` | White / paper backgrounds |
| `favicon.svg` | Browser tab icon |
| `apple-touch-icon.png` | iPhone home-screen icon |

**Wordmark:** `NEARFEELD`, all caps, set in JetBrains Mono with wide tracking (letter-spacing ≈ 0.3em).

**Do**
- Leave clear space around the mark at least equal to the height of the dot ×2
- Keep the dot sage and the arcs off-white (or black on light backgrounds)

**Don't**
- Recolor the arcs, add gradients, glows or drop shadows
- Rotate, stretch, or add a 4th arc
- Put the mark on busy photos without a dark overlay

## 2. Color

| Name | Hex | Role |
|---|---|---|
| **Ink** | `#0E0E0E` | Background: deep space |
| **Panel** | `#141413` | Cards, raised surfaces |
| **Line** | `#262624` | Hairlines, dividers, orbit rings |
| **Paper** | `#F5F5F2` | Headlines, icons, primary buttons |
| **Fog** | `#D9D9D4` | Body text |
| **Muted** | `#8E8E89` | Labels, secondary text |
| **Field (sage)** | `#8FA89D` | The signal. Accents only: product codes, "Coming soon", the cell |

**Rule of thumb:** about 90% ink, 9% paper, 1% sage. Sage is a highlight, never a background.

---

## 3. Type

| Font | Use | Settings |
|---|---|---|
| **Space Grotesk** (Medium 500) | Headlines, product names | Tight: letter-spacing −0.02em |
| **Space Grotesk** (Regular 400) | Body copy | Line-height 1.5 |
| **JetBrains Mono** (Regular 400) | Labels, codes, nav, buttons | ALL CAPS, letter-spacing 0.22em |

Both fonts are free on Google Fonts.

---

## 4. Naming system

Every product gets a **letter code plus a set number**, like hardware part numbers:

| Code | Product |
|---|---|
| C-01 | Card |
| S-01 | Shoe Insert |
| K-01 | Keychain |
| V-01 | Car Vent |
| H-01 | Hanger Clip |
| R-01 | Refill cells |

Collections are **SETS** (SET 01, SET 02…). Count items as `01/05`, never "1 of 5".

---

## 5. Voice

Short. Calm. Confident. Mostly two-to-six-word sentences. Talk like a well-designed instruction manual, with a little space-mission flavor.

- ✅ "Scent you carry." · "One cell. Five carriers." · "Snap. Slide. Scent." · "Signal lost."
- ❌ "The ULTIMATE fragrance hack you NEED!!! 🔥🔥"

Space words to use sparingly: *signal, field, range, transmit, orbit, set, unit.*

## 7. Space motifs (website)

Keep these subtle. They should feel like a background hum, never a sci-fi costume.

- Sparse starfield with an occasional shooting star
- Thin orbit rings around the logo with a small sage "satellite"
- Telemetry-style labels: `STATUS — PRE-LAUNCH`, `SIGNAL ACTIVE`
- Corner brackets that appear on hover, like a camera viewfinder
- Dotted lines = perforation = the refill cell
